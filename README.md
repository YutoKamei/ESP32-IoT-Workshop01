# ESP32でIoTシステムを作ってみよう！

> 高校生向け研究室体験実習 | 温度測定 → サーバ送信 → スマートフォンで確認

## 今日のゴール

ESP32と温度センサを使って温度を測定し、Wi-Fiでサーバへ温度データを送信して、スマートフォンのWeb画面から確認します。最後は温度変化の実験結果を簡単に発表します。

**初めてプログラミングする人も大丈夫です。** 各STEPには「基本課題」と、早く終わった人向けの「チャレンジ課題」があります。困ったら担当者に聞いてください。

## どんな仕組み？

```text
温度センサ（DS18B20）
       ↓ 温度の数値
ESP32（小さなコンピュータ）
       ↓ Wi-Fi / インターネット
サーバ（温度を受信・保存）
       ↓ Web画面
スマートフォン（温度・グラフを見る）
```

- **温度センサ**：現実世界の温度を測定する部品。
- **ESP32**：センサの値を読み取り、通信するマイコン。
- **サーバ**：送られたデータを受け取り保存するコンピュータ。
- **IoT**：モノをネットワークにつないで、データを活用する仕組み。

## 今日の約束

1. 配線は **USBケーブルを外した状態** で行います。
2. 水を扱う実験では、**防水対応のセンサ先端だけ** を水につけます。ESP32や接続部はぬらしません。
3. 途中でつまずいたら、無理に進めず担当者と確認します。
