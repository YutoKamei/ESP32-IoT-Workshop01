# 事前準備：使うものを確認しよう

[🏠 トップ](../README.md) | [次へ：STEP 1 →](01-temperature.md)

## このページの目標

実習で使う機材と開発環境を確認し、ESP32にプログラムを書き込める状態にします。

> [!NOTE]
> **実習で使用する機材は、すべてこちらで用意しています。**
>
> 自分で購入する必要はありません。
>
> このページでは、研修後も自分で電子工作に挑戦したい人に向けて、各部品の購入先も紹介しています。

## 1. 必要なもの

今回の実習では、以下の機材を使用します。

| 機材 | 役割 |
| --- | --- |
| ESP32開発ボード（例：ESP32-DevKitC） | 温度を読み取り、サーバへ温度データを送る |
| DS18B20（温度センサ） | 温度を測る |
| 4.7kΩ抵抗 | センサの信号線を安定させる |
| ブレッドボード | はんだ付けせずに部品を接続する |
| ジャンパーワイヤ | 部品同士を電気的につなぐ |
| USB **データ通信** ケーブル | ESP32とPCを接続する |
| Arduino IDEが使えるPC | プログラムを編集して書き込む |
| スマートフォン | Web画面でデータを見る |

> [!IMPORTANT]
> **温度センサの端子について**
>
> センサの配線色は製品によって異なります。
> 色だけで判断せず、使用する製品の**VDD / DQ / GND** の説明を確認しましょう。

## 3. Arduino IDEを開く

Arduino IDEは、マイコン用プログラムを作成して書き込むためのソフトです。

今回は、このソフトを使ってESP32にプログラムを書き込みます。

### 3-1. Arduino IDEを起動する

1. PCで **Arduino IDE** を開きます。
2. ESP32をUSBケーブルでPCに接続します。
3. **ツール → ボード** から使用するESP32に対応するボードを選択します（例：**ESP32 Dev Module**。講師指定があればそれに従う）。
4. **ツール → ポート** から接続したESP32のポートを選択します。
5. ポートが表示されなければ、USBケーブルやドライバーを担当者と確認しましょう。

### 3-2. ESP32のボード設定について

Arduino IDEでESP32を使用するには、ESP32用のボードパッケージが必要です。

研修では、あらかじめ講師側でインストールしています。

自宅のPCなどで開発する場合は、以下の公式ページを参考に設定してください。

📖 **[ESP32公式インストール手順（Espressif Systems）](https://docs.espressif.com/projects/arduino-esp32/en/latest/installing.html)**

Arduino IDEのボードマネージャーで**esp32 by Espressif Systems** をインストールします。

## 4. ライブラリを確認する

**ライブラリ** は、プログラムで使える便利な機能をまとめたものです。

今回の実習では、温度センサを扱うために以下の2つを使用します。

| ライブラリ名 | 役割 |
| --- | --- |
| `OneWire` | DS18B20との通信に使用する |
| `DallasTemperature` | DS18B20から温度を取得する |

実習では講師側でインストール済みなので、基本的には追加作業は不要です。
