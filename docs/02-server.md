# STEP 2：測定した温度をサーバへ送ろう

[🏠 トップ](../README.md) | [← STEP 1](01-temperature.md) | [次へ：STEP 3 →](03-smartphone.md)

## このSTEPの目標

**ESP32をWi-Fiに接続し、測った温度をサーバに送信します。**

## 1. Wi-Fiとサーバの役割

```text
[DS18B20] → [ESP32] →（Wi-Fi）→ [サーバ]
                               ↑
                     測定した温度を受け取る
```

- **Wi-Fi**：ESP32をネットワークへ接続するしくみ。
- **サーバ**：送られたデータを受信し、保存するコンピュータ。
- **HTTPS**：Webで情報を暗号化して送受信する通信方法。
- **JSON**：データを「名前：値」の組み合わせで表す形式。

## 2. 送信するデータを見てみよう

今回の研修では次のようなJSONを送ります（数値は例です）。

```json
{
  "deviceId": "group01",
  "temperature": 24.5
}
```

`deviceId` はグループを区別するための番号、`temperature` は測定した温度です。サーバ側で受信時刻を記録する構成を想定します。

## 3. 自分のグループ番号を確認する

講師から渡された値を記入します。

- グループ番号：`group____`
- 送信先：講師が指定した **研修専用サーバ**

> **大切**：サーバURLや認証方式は研修前に講師側で設定します。パスワード、APIトークン、証明書の秘密鍵をGitHubの公開リポジトリや画面写真に載せないでください。

## 4. 送信プログラムを用意する

[STEP 2のひな形](../code/step2/step2.ino) には、温度測定に加えて、Wi-Fi接続とHTTPS送信の処理が含まれています。

**このひな形は講師が研修環境に合わせて設定を完了させてから配布する教材です。** このままではサーバへ送信できません。講師が用意した設定済みファイルをArduino IDEで開いてください。

プログラム中には、次のような部分があります。

```cpp
const char* DEVICE_ID = "group01";
const unsigned long SEND_INTERVAL_MS = 5000;
```

- `DEVICE_ID`：自分のグループの番号
- `SEND_INTERVAL_MS`：何ミリ秒ごとに送信するか（5,000ms = 5秒）

## 5. 温度を送信する

1. ESP32のUSB接続とボード・ポート設定を確認します。
2. **講師が設定したSTEP 2のプログラム**を書き込みます。
3. シリアルモニタを115200 baudで開きます。
4. Wi-Fiに接続できたこと、送信に成功したことを確認します。
5. 講師側でサーバにデータが届いたことを確認します。

シリアルモニタの表示例（実際のメッセージは設定したプログラムによって異なります）：

```text
Connecting Wi-Fi...
Wi-Fi connected
Temperature: 24.50 C
HTTP status: 200
```

> HTTPの `200` は、サーバから正常な応答が返ったことを示します。**保存が成功したことはサーバ側でも確認**しましょう。実際のAPIによって成功時のステータスコードは変わります。

## ✅ 基本課題

- [ ] ESP32をWi-Fiに接続できた
- [ ] シリアルモニタで送信結果を確認できた
- [ ] サーバに自分のデバイスのデータが届いた
- [ ] `deviceId` が何を表すか説明できる
