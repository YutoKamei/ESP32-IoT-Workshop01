# STEP 3：スマートフォンで温度を確認しよう

[🏠 トップ](../README.md) | [← STEP 2](02-server.md) | [次へ：STEP 4 →](04-experiment.md)

## このSTEPの目標

**ESP32から送信した温度を、スマートフォンのWeb画面で確認します。**

## 1. なぜスマホで見られるの？

```text
ESP32 ──温度を送信──> サーバ ──温度を取得──> スマートフォン
```

スマートフォンはESP32に直接接続しているわけではありません。サーバに保存された情報をWebページから読み取ることで、温度を確認します。

## 2. Webページを開く

1. 講師が配布する **研修用WebページのQRコード** を読み取ります。
2. Webページを開きます。
3. グループ番号（例：`group01`）を選択します。
4. 最新温度とグラフが表示されるか確認します。

> URLやQRコードは、講師が研修専用Web画面を構築した後に配布します。公開リポジトリには認証用の秘密情報を記載しません。

## 3. 見るポイント

- **最新温度**：最後に受信した温度は何℃か。
- **最終更新時刻**：その温度はいつ測定・受信したものか。
- **履歴グラフ**：時間とともに温度がどう変化しているか。

「現在の温度」という表示でも、更新が止まっている可能性があります。**更新時刻も必ず確認しましょう。**

## 4. 温度を変えてみよう

1. グラフを開いて、現在の温度を記録します。
2. センサ先端を指でしばらく温めます。
3. グラフの線がどのように変化するか観察します。
4. 指を離して室温に戻る様子も観察します。

**注意**：画面が自動更新されない構成の場合は、講師の指示に従って更新ボタンを押してください。送信・画面更新の間隔によって反映に時間差が生じます。

## ✅ 基本課題

- [ ] スマートフォンでWebページを開けた
- [ ] 自分のグループの温度を表示できた
- [ ] 温度グラフと更新時刻を確認できた
- [ ] センサを温めたときの変化を確認できた
