# STEP 4：温度を変えて実験してみよう

## このSTEPの目標

**センサの温度を変化させ、結果をグラフや数値から読み取って考察します。**

## 1. 実験前に予想しよう

次の問いに答えてから実験を始めましょう。

- センサを指で温めると、表示温度はどのように変わるでしょうか？
- 指を離した後、温度はどうなるでしょうか？
- センサを触った瞬間に温度は変わるでしょうか、それとも少し遅れるでしょうか？

**予想：**

> （ここに予想を書きましょう。ノートや配布ワークシートに記録してもOKです。）

## 2. 基本実験：指で温める

1. センサを室温に十分なじませます。
2. 測定を開始し、**温める前の温度** を記録します。
3. センサの金属先端を **約30秒間** 指で温めます。
4. 指を離し、さらに **約60秒間** 測定します。
5. スマホのグラフから、温度の変化を確認します。

> 時間は目安です。送信・測定間隔に応じて講師が調整してください。

## 3. 結果を記録しよう

| 温度の上昇量（最高 − 最初） | ______ ℃ |
| 指を離した後の変化 | __________________ |
| グラフの特徴 | __________________ |

**グラフを1枚保存** しておきましょう。Web画面に画像保存機能がない場合は、講師の指示に従いスクリーンショットを撮影します。個人情報や認証情報が画面に写らないよう注意します。

## 4. 考察してみよう

- 予想と結果は同じでしたか？
- 触り始めてから最高温度になるまでに時間がかかったのはなぜでしょうか？
- スマホのグラフには、測定したすべての瞬間が記録されていますか？

## ⭐ チャレンジ課題（好きなものを1つ）

### A. 冷水を使った実験

**講師が用意した防水型センサに限り**、金属製の測温部だけを冷水につけて変化を観察します。**ESP32本体や配線接続部は水に近づけません。** 非防水センサでは実施しません。

### B. 送信間隔の比較

送信間隔を5秒と10秒に設定し、同じ長さだけ測定したときのグラフの点の数を比較します。センサの測定処理にも時間がかかるため、実際の時刻で比較しましょう。

### C. 温度の警告表示

温度が決めた値を超えたら、シリアルモニタに警告を表示するようにプログラムを改良しましょう。
