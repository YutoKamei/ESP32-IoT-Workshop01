# 困ったときのチェックリスト

[🏠 トップ](../README.md) | [STEP 1](01-temperature.md) | [STEP 2](02-server.md) | [STEP 3](03-smartphone.md)

困ったときは、**①何が起こったか → ②いつから起こったか → ③画面のメッセージ** を確認しましょう。解決しないときは担当者に相談してください。

## Arduino IDEで書き込めない

- USBケーブルは **データ通信対応** ですか？（充電専用だと書き込めません）
- 使用するESP32に対応した **ボード** が選択されていますか？
- 正しい **ポート** を選択していますか？
- シリアルモニタを閉じて、再度書き込んでみましょう。
- 書き込み待機状態に入れない機種では、担当者の指示に従って **BOOTボタン** を操作します。

## `OneWire.h` / `DallasTemperature.h` が見つからない

Arduino IDEのライブラリマネージャで `OneWire` と `DallasTemperature` をインストールしたか確認してください。

## 温度が表示されない・`Sensor error` が出る

**USBケーブルを外してから** 配線を確認してください。

- VDD → 3.3V、GND → GND、DQ → GPIO17 になっていますか？
- DQと3.3Vの間に **4.7kΩ抵抗** が入っていますか？
- DS18B20の配線色を、商品の仕様で確かめましたか？
- シリアルモニタを **115200 baud** にしましたか？
- `-127` などの値は、センサ未検出を示すことがあります。

## Wi-Fiにつながらない

- 研修用の **2.4GHz Wi-Fi** に接続していますか？
- 講師が設定したSSID・パスワードを利用していますか？
- Wi-Fiの電波が届いていますか？
- 研修用ネットワークに認証画面などが必要なら、講師に相談してください。

## サーバへ送信できない

- 温度測定そのものは成功していますか？
- Wi-Fi接続は成功していますか？
- シリアルモニタに **HTTPのステータスコード** やエラー表示がありますか？
- 講師から渡された **送信設定済みプログラム** を使用していますか？
- デバイスIDは自分のグループのものになっていますか？

通信エラーが発生しても、**認証情報や秘密鍵をチャットや公開ページへ貼り付けないでください。**

## スマホで温度が見えない

- 正しいWebページとグループ番号を開いていますか？
- 画面に表示される **更新時刻** は新しいですか？
- 自動更新がない場合は、更新操作を行いましたか？
- ESP32側でサーバへの送信が成功していますか？

## 担当者に伝えるとよいこと

1. 取り組んでいるSTEP
2. 画面に出たメッセージ（**秘密情報は伏せる**）
3. 直前に変更したコードや配線
4. 試してみた対処法
